# College Admission Chatbot

## 📌 Project Description
This project is a chatbot designed to answer common college admission queries using Natural Language Processing (NLP).

## 🎯 Features
- Answers admission-related questions
- Uses TF-IDF and cosine similarity
- Simple and user-friendly interface
- Fast response system

## 🛠 Technologies Used
- Python
- Flask
- HTML, CSS, JavaScript
- Scikit-learn

## ▶ How to Run
1. Install Python
2. Install libraries:
   pip install flask scikit-learn flask-cors
3. Run:
   python app.py
4. Open index.html in browser

## 📊 Future Improvements
- Voice input
- Multi-language support
- AI-based model (BERT)
